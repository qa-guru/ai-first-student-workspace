RAG: факты с полки, не догадки 7b

Skill говорит «прочитай 2–4 чанка». Без RAG модель выдумывает task testE2e и $("input"). С RAG — data-testid, fluent, текст ошибки, стенды.

без чанков · «на глаз»

// в LoginTests.java
$("#login").setValue("user1");
$("#pass").setValue("123");
$(".btn-primary").click();
$(".alert").shouldHave(text("Invalid"));

./gradlew testE2e          // такого task нет
open("https://ai-first.autotests.ai/login");
                           // URL не из properties

skill назвал чанки · агент их прочитал

po-locators   LoginPage:
  $("[data-testid='login-input']")
  $("[data-testid='password-input']")
  $("[data-testid='submit-button']")
  $("[data-testid='error-message']")

po-fluent     return this / HomePage
test-negative один текст, @Tag("negative")
cfg-stands    URL из config; user1 есть на
              pipeline / stage / prod
              (wrong password сид не сносит)
ci-gradle-args  task testE2e нет; tags + -Denv
Не RAGСкармливать всю папку rag/. «Прочитай стеллаж» → 7b тонет и снова рисует testE2e.
2–4 idДля этого промпта: po-fluent · po-locators · test-negative · cfg-stands. JSON 401 — ещё test-api-layer, это уже развилка ADR (лист 24).
