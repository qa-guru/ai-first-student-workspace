    typeUsername(username).typePassword(password).submit();
    return new HomePage();
  }

  LoginPage typeUsername(String username) {
    loginInput.setValue(username);
    return this;
  }

    return this;
  }

# Разработай автотест

RAG до кода: po-fluent, po-locators, po-step,
test-negative, test-taxonomy, test-layers, cfg-stands.

## When
«напиши e2e», «добавь negative login»

## Do not
- CSS/xpath в *Tests
- новый ChromeDriver в тесте
- localhost / prod URL в Java
- commit без OK

## Steps
1. Один @Layer
2. Стенды pipeline / stage / prod
3. Расширь PO, локаторы не в тесте
4. @Tag яруса + positive/negative
5. ./gradlew test -Denv=ci -DincludeTags=e2e \
     -Dtest=LoginTests#<method>

## DoD
слой, стенды, exit, без commit

как попадает: «прочитай SKILL.md»

When  напиши e2e / покрой логин
Don't CSS в *Tests, ChromeDriver, URL в Java, commit
Шаги  слой → стенды → PO → -Dtest=
DoD   слой, стенды, exit, без commit

# ADR 005: screenshot — slice, не слой
Статус: принято

Контекст: хочется ярус скриншотов.
Пиксельный diff — тот же браузерный сценарий,
другой отбор.

Решение:
- *ScreenshotTests остаются @Layer("e2e")
- отбор: @Tag("screenshot")
- @Tag("smoke") тоже slice, не ярус
- task testE2e нет

401 JSON — это api (AuthApiTests),
не новый e2e-клик.

как попадает: skill ссылается, сам не копирует

401 JSON → AuthApiTests, не клик
screenshot = @Tag, не @Layer
smoke тоже slice, не ярус
